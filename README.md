# Academic & Professional Portfolio

A clean, responsive portfolio page built to embed directly into a business website without breaking the host site's design.

## 🌐 Live Site
The portfolio is live at:  
👉 **[www.mogulfilmz.com/student](https://www.mogulfilmz.com/student)**

---

## 🛠️ Built With

- **Gemini:** Used as an AI collaborative partner to optimize site layouts, write clean media query overrides, and structure responsive features.
- **HTML5 & CSS3:** Structured with semantic markup and customized with variables to easily match dark themes.
- **Vanilla JavaScript:** Handles the responsive mobile menu and interactive project filtering layout without bulky external frameworks.
- **Google Fonts API:** Uses Syne and DM Sans for modern typography.
- **Pixieset:** Site is hosted and embedded on Pixieset.

---

## 🚀 Key Features

- **AI Internship & Project Focus:** Highlights ongoing work in agentic AI automation, predictive machine learning pipelines, and technical engineering milestones.
- **Embedded Layout Spacing Fixes:** Custom CSS resets that completely eliminate template padding gaps at the top and bottom of the page.
- **Interactive Project Filters:** Quick tabs to sort between Engineering/ML projects and Multimedia work instantly.
- **Responsive Navigation:** A header navigation system that automatically adapts to desktop viewports and shrinks into a clean sidebar menu on mobile.
- **Scroll Animations:** Lightweight, high-performance visual fade-ins that trigger naturally as a user scrolls down the page.
