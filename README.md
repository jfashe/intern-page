# Academic & Professional Portfolio

Welcome to my responsive, interactive portfolio page built to embed directly into my business website without breaking the host site's (Pixieset's) design.

## Live Site
The portfolio is live at:  
**[www.mogulfilmz.com/student](https://www.mogulfilmz.com/student)**

---

## Built With
Gemini, Claude, Vanilla JS and Google Fonts API.
Hosted and embedded on Pixieset.

---

## Key Features

- **AI Internship & Project Focus:** Highlights ongoing work in all my ml and ai-related work 
- **Interactive Project Filters:** Quick tabs to sort between Engineering/ML projects and multimedia work instantly.
- **Responsive Navigation:** A header navigation system that automatically adapts to desktop viewports and shrinks into a clean sidebar menu on mobile.
- **Scroll Animations:** Lightweight, high-performance visual fade-ins that trigger naturally as a user scrolls down the page.
